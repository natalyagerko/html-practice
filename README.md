# Практическое задание «Введение в HTML»

## О проекте

Проект разработан в рамках выполнения практического задания. 

В проект входят четыре веб-страницы, демонстрирующие основные возможности HTML.

## Содержание проекта

1. first-page.html — базовая HTML-страница.
2. index.html — персональная веб-страница.
3. feedback.html — форма обратной связи.
4. semantic.html — страница с семантической разметкой HTML5.

## Используемые технологии

- HTML5
- Текстовая разметка
- HTML-формы
- Гиперссылки
- Таблицы и списки
- Семантические элементы
- Мультимедийные элементы

## Инструкция по запуску

1. Склонируйте репозиторий или скачайте проект в формате ZIP.
2. Распакуйте архив.
3. Откройте папку проекта.
4. Запустите нужную страницу двойным нажатием на HTML-файл.
5. Страница откроется в браузере.

Для просмотра страниц используйте файлы:
- first-page.html
- index.html
- feedback.html
- semantic.html
