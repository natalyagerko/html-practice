Моя первая веб-страница

HTML — язык разметки, который используют для создания структуры веб-страниц. С его помощью задают заголовки, абзацы, списки, ссылки и другие элементы. HTML помогает браузеру понять, как организовать содержимое страницы.

В отличие от языков программирования, HTML сам по себе не задаёт алгоритмы и не выполняет вычисления: он описывает структуру и смысл содержимого. Например, HTML не заменяет JavaScript, который позволяет добавлять интерактивное поведение.
Внешний вид страницы обычно оформляют с помощью CSS.
